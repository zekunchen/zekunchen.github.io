# Zekun Chen's Academic Homepage

This repository contains the source code for Zekun Chen's academic homepage, published with GitHub Pages at [https://zekunchen.github.io](https://zekunchen.github.io).

The site is based on [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io), with content customized for a personal academic profile.

The homepage supports both English and Chinese:

- English: [https://zekunchen.github.io](https://zekunchen.github.io)
- 中文: [https://zekunchen.github.io/zh/](https://zekunchen.github.io/zh/)

The website includes information about research interests, education and academic experience, and publications. Publication citation statistics are updated using Google Scholar data.
